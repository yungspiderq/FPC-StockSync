# 🔄 StockSync — Синхронизация лотов автовыдачи

Плагин для [FunPay Cardinal](https://github.com/sidor0912/FunPayCardinal) **v0.1.17+**

Держит поле **«Наличие»** лотов на FunPay в соответствии с реальным количеством
товаров в товарных файлах автовыдачи (`storage/products/*.txt`).

**Проблема:** «Наличие» на FunPay и товарный файл живут отдельной жизнью — после
ручного пополнения товара, частичных возвратов или сбоев цифры расходятся.
Покупатели видят несуществующие остатки («100 шт.», хотя товара 3) или наоборот.

**Решение:** плагин автоматически приводит «Наличие» к фактическому числу товаров.

## Возможности

- ⚡ **Синхронизация сразу после каждой автовыдачи** (событие POST_DELIVERY) —
  товар выдан, «Наличие» тут же уменьшено.
- 🔁 **Периодическая полная синхронизация** всех лотов автовыдачи (по умолчанию
  каждые 10 минут) — ловит ручные пополнения файлов и любые расхождения.
- 🔄 **Ручная кнопка «Синхронизировать сейчас»** с подробным отчетом в чат
  (проверено / обновлено / пропущено / ошибки + список изменений «100 → 7»).
- 🔔 Уведомления **только о реальных изменениях** — без спама.
- 🩺 **Диагностика конфигов**: какие секции `auto_delivery.cfg` НЕ подходят ни
  одному активному лоту — значит лот переименовали и автовыдача по нему молча
  не сработает. Проблемные секции показываются первыми с ⚠️.
- 🔒 **Безопасность**:
  - меняет ТОЛЬКО поле «Наличие» — цена, название, описание не трогаются;
  - лоты со встроенной автовыдачей FunPay пропускаются (там наличие из «секретов»);
  - лоты с нулём товаров пропускаются (нулем занимается автовыключение Кардинала);
  - сопоставление лотов с конфигами — по тому же алгоритму «самого длинного
    совпадения», что использует сам Кардинал;
  - анти-флуд паузы между сохранениями.

## Установка

```bash
cd /home/fpc/FunPayCardinal
wget https://raw.githubusercontent.com/yungspiderq/FPC-StockSync/main/stock_sync.py -O plugins/stock_sync.py
sudo systemctl restart FunPayCardinal@fpc
```

или отправьте файл боту в Telegram → `🔌 Плагины` → `➕ Добавить плагин`.

## Использование

Команда **`/sync`** (или `⚙️ Настройки` на странице плагина):

| Кнопка | Действие |
|---|---|
| 🔄 Синхронизировать сейчас | Полная синхронизация + подробный отчет в чат |
| 🩺 Диагностика конфигов | Секции автовыдачи ↔ активные лоты (⚠️ = нет совпадений) |
| 🟢/🔴 Периодическая: ВКЛ/ВЫКЛ | Фоновая синхронизация по интервалу |
| 🟢/🔴 После выдачи: ВКЛ/ВЫКЛ | Мгновенная синхронизация лота после автовыдачи |
| ⏱ Интервал: 10 мин. | Период полной синхронизации (2–120 мин.) |

### Пример уведомления

```
🔄 StockSync: «Наличие» синхронизировано.

Обновлено лотов: 2
• Аккаунты Steam с играми: 100 → 7
• Ключи Steam: 12 → 3
```

## Важно знать

- Синхронизируются только **активные** лоты, у которых в конфиге автовыдачи
  указан `productsFileName`.
- Если в файле 0 товаров — «Наличие» не трогается: такой лот деактивирует
  автовыключение Кардинала (а при появлении товаров следующий цикл синхронизации
  выставит реальное число).
- Один товарный файл на несколько лотов поддерживается: все они получат одинаковое
  «Наличие» по числу товаров в файле.
- Каждый цикл синхронизации — по одному запросу на лот (+ сохранение при
  расхождении). Для десятков лотов это незаметно, паузы анти-флуд включены.
- Настройки: `storage/plugins/stock_sync/settings.json`.

## Состав репозитория

- `stock_sync.py` — плагин (класть в `plugins/`).
- `tests_plugin_stock_sync.py` — тесты (46 проверок на моках: сопоставление лотов
  и конфигов, все статусы синхронизации, antispa-уведомления, POST_DELIVERY,
  диагностика, busy-lock, весь Telegram-UI, настройки). Запуск из корня FunPayCardinal:
  ```bash
  cp tests_plugin_stock_sync.py /path/to/FunPayCardinal/
  cd /path/to/FunPayCardinal && pip install -r requirements.txt && python3 tests_plugin_stock_sync.py
  ```
